# Plano — aplicativo Web responsivo

1. Estender os tokens de layout Web com as classes de janela e larguras já publicadas na referência do design system.
2. Criar uma leitura única da classe de janela para a View e componentes de contêiner reutilizáveis, sem levar lógica de domínio às telas.
3. Adaptar acesso e cadastro; validar os estados compactos e largos antes de avançar.
4. Adaptar navegação autenticada; confirmar rotas, seção ativa e teclado.
5. Adaptar descoberta, listas, detalhes, formulários e telas auxiliares por padrão de conteúdo, preservando Android/iOS.
6. Executar verificações locais e revisão do diff. Registrar limitações de inspeção visual e fluxos reais em `verify.md`.

Decisão arquitetural: [ADR 0037](../../docs/adr/0037-layout-responsivo-do-app-web.md).

# Plano

Manter Expo 57, React DOM e MVVM existentes. Estado de navegação em hook; componente visual reutilizável para apresentação. Sem dependências novas: Web Animations API anima faixas da folha com transformações 3D e sombra, evitando um painel rígido. Clones decorativos ficam inertes, sem IDs e sem árvore acessível. Cancelar animações ao desmontar ou redimensionar.

A referência Figma 53:185 mantém a identidade. A navegação em livro é divergência solicitada explicitamente pelo usuário, sem correspondente na landing do Figma. Tokens específicos para duração, perspectiva e barra de navegação.

Validar com Playwright MCP em desktop e celular, incluindo voltar, links diretos, gestos, movimento reduzido, foco e ausência de overflow externo. Testes existentes, TypeScript e exportação Web.

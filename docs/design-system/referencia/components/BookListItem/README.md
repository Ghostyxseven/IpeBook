# BookListItem

Item de três linhas para listas de livros (Explorar, Favoritos): capa 56×78, título `m3-title-md`, autor e metadados `m3-body-md`, tag da modalidade e botão de favoritar (48px) à direita.

Divisor `outline-variant` entre itens; o último não tem divisor. Item selecionado (tablet, lista e detalhe) usa `secondary-container` com raio `radius-md`.

# NavigationBar
Barra inferior de 80px com os quatro destinos: Início, Explorar, Estante, Perfil. Destino atual com indicador de 64×32 em `secondary-container` e `aria-current="page"`.

Some dentro de fluxos (anunciar, combinar encontro, detalhe do livro), que usam a barra de ações inferior. No tablet vira **navigation rail** (88px, FAB "Anunciar" no topo); na Web, links no cabeçalho.

# IOSGroupedList

Lista agrupada (inset grouped) para formulários e configurações no iOS: células `ios-cell` de 44pt ou mais, cantos `radius-ios-cell`, separador 0.5pt `ios-separator` recuado 16pt.

Cabeçalho em `ios-footnote` maiúsculo e rodapé explicativo em `ios-footnote`. Valor à direita em `ios-secondary-label`; seta só quando a célula navega.

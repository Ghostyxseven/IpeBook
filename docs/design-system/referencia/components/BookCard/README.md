# BookCard

Cartão preenchido (`surface-container`, `radius-md`) para grades: Início em 2 colunas no celular, 5 na Web. Capa em cima (cor `cover-*` com a ilustração de sol e montanhas), título, autor e tag.

A capa é ilustrativa até o anunciante enviar uma foto; nesse caso a foto ocupa a mesma área com `object-fit: cover`.

# Tag
Etiqueta de modalidade do anúncio. É o código de cor do IpêBook e aparece igual em todo lugar.

| Modalidade | Fundo | Texto |
| --- | --- | --- |
| Venda | `secondary-container` | `on-secondary-container` |
| Troca | `tertiary-container` | `on-tertiary-container` |
| Doação | `doacao-container` | `on-doacao-container` |

A cor nunca é o único sinal: o texto da tag sempre diz a modalidade.
